# NordicWork Check

MVP платформы проверенных вакансий в Швеции и Норвегии для работников из Балтии.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Текущий этап

- Главная страница.
- Демонстрационные карточки вакансий.
- Информационные поля: зарплата, жильё, транспорт, график и уровень проверки.
- Следующий этап: каталог, фильтры, Prisma/Supabase, админская модерация и форма работодателя.

## Принцип

Платформа не принимает документы кандидатов и направляет отклик на официальный источник вакансии.
