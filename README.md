# NordicWork Check

Платформа проверенных вакансий в Швеции и Норвегии для работников из Балтии.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Без `.env.local` сайт работает на демо-данных.

## Supabase

1. Создать проект на supabase.com.
2. В SQL Editor выполнить `supabase/schema.sql`.
3. Скопировать `.env.example` → `.env.local` и вписать URL и anon key (Settings → API).

## Текущий этап

- Главная, страница методики `/how-we-check`, страница работодателя `/for-employers`.
- Карточка вакансии: зарплата, жильё, дорога, часы, договор, уровень проверки, ссылка на оригинал.
- Данные — демо-набор из `src/lib/vacancies.ts` до подключения Supabase.

## Принцип

Уровень проверки (`verification_level`) ставит только редакция. Оплата меняет только тип публикации
(`publication_type`) — охват и перевод, но не плашку. Платформа не принимает документы кандидатов и
направляет отклик на официальный источник вакансии.
